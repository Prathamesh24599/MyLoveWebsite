# MyLoveWebsite ❤️

A mobile-friendly romantic surprise made with plain HTML, CSS and JavaScript. No images or frameworks.

## Run
Open `index.html` in a browser.

## Customize
- Change the message in `js/script.js` (`loveNote`).
- Change the sender name in `index.html` (currently **Love**).

## Publish for a WhatsApp link
Upload this folder to a GitHub repository, then enable GitHub Pages in Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Share the generated HTTPS URL. You can also deploy the folder using Netlify Drop.
